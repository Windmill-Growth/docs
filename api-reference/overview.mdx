Use the public REST API for application reads. Use MCP when an AI client should read workspace data and perform supported, authorized actions.

| Connection | Authentication | Workspace selection |
| --- | --- | --- |
| REST and audience analytics | API key | The key's workspace |
| MCP | OAuth access token | The authorized default or an explicit `workspaceId` |

## Endpoints

REST base URL:

```text
https://api.traxy.ai/api/v1
```

MCP endpoint:

```text
https://api.traxy.ai/api/v1/mcp
```

Endpoint reference pages describe the public contract. The in-app Agent has additional capabilities that are not necessarily available through public MCP. Use the public tool catalog rather than assuming every app action has an MCP equivalent.
