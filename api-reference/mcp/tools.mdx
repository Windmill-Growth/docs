The tables below list public tools by group. Scope and workspace filtering decide which tools your connection sees, so use `tools/list` to discover the tools and argument schemas your connection can actually use.

Tool names retain `watchlist` and `organization` where those are part of the public contract. In the app, these correspond to tracked profiles and your workspace. Tools with `outbound` in the name work with campaigns.

## Confirm actions

Select the workspace, target, and action before making a write request.

- `traxy_start_agent_run` and `traxy_qualify_linkedin_post` require `confirmLeadUsage: true` after the user agrees that new qualified people may consume pipeline capacity.
- `traxy_apply_lead_action` supports `snooze`, `done`, `good`, `bad`, and `client`. The `done` action needs `confirmDone: true`.
- Contact enrichment needs an explicit request. Email and phone follow the workspace's entitlements and do not consume pipeline capacity.
- ICP and Signal Brief updates replace supplied arrays and leave omitted fields unchanged. Inspect the current configuration before sending replacements.
- Webhook-style destination tools support Webhook, Clay, n8n, and Zapier. Queuing delivery is not proof that the receiver accepted it.
- Actions that launch or change a campaign or sequence, send a message, reply, or use capacity are confirmed with the user first. The AI client shows what it will do and waits for a yes before it calls the tool.
- `traxy_send_outreach_message` and `traxy_reply_inbox_conversation` require `confirmSend: true` after the user approves the exact message. Each call sends one message to one lead.
- Drafting and testing a campaign sends nothing. A campaign's delivery mode is `HUMAN` (the user approves each lead's messages) or `AUTO` (messages go out as written). Ask the user which one to use.
- `traxy_launch_campaign` needs a fresh `operationId`. If the launch fails partway, retry with the same `operationId`; the result names the step that failed.

The former `confirmCreditSpend` argument is not accepted. Sending it returns `validation_failed`; use only the current schema. The capacity tool replaces the former Agent budget-status tool.

See [workspace selection](/api-reference/mcp/workspaces) and [error handling](/api-reference/pagination-and-errors) when building a client.
