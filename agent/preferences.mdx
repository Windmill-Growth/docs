---
title: "Memory and daily brief"
description: "Manage what the Agent remembers and configure your daily brief."
---

Open **Settings** > **Agent** to review memory and the daily brief.

## Manage memory

Memory helps the Agent keep useful context across conversations. Review saved entries and remove anything that is outdated or no longer relevant.

Personal memory applies to your own work. Workspace memory supplies shared context. Choose the intended scope when you ask trax to remember something; avoid adding sensitive information that other members should not use.

Memory is separate from **Lead criteria** and **Signals**. To change qualification, review and save the relevant targeting configuration.

## Configure the daily brief

Use the daily brief controls to choose whether it is enabled, its available delivery channel, and its delivery time. Review the destination before saving.

If you choose Slack, connect the intended workspace and channel first. If a brief does not arrive, check its enabled state and the Slack connection before changing your targeting.
