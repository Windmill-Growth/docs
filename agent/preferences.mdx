---
title: "Memory and archived chats"
description: "Manage what trax remembers and return to archived conversations."
---

Open **Settings** > **Agent** to review memory and archived chats.

## Manage memory

Memory helps the Agent keep useful context across conversations. Review saved entries and remove anything that is outdated or no longer relevant.

Personal memory applies to your own work. Workspace memory supplies shared context. Choose the intended scope when you ask trax to remember something; avoid adding sensitive information that other members should not use.

Memory is separate from **Lead criteria** and **Intent signals**. To change qualification, review and save the relevant targeting configuration.

## Return to archived chats

Under **Archived chats**, choose **Open** to read an earlier conversation. Choose **Restore** to return it to the sidebar.

Restoring a chat does not repeat its actions. Review its previous results before asking trax to continue.
