## Before you connect anything

Owners and admins set up integrations and change delivery settings.

## Available integrations

The current public integrations are:

- **API & MCP** for API keys and OAuth-based MCP access
- **Ordinal** for connecting Ordinal to traxy with a dedicated integration key
- **Slack** for qualified lead alerts and workspace activity notifications
- **HubSpot** for creating or updating CRM contacts, companies, and activity from qualified leads
- **Webhook** for signed qualified lead alerts and activity notifications sent to another system
- **Zapier** for sending qualified lead alerts and activity notifications to a Zapier webhook
- **Clay** for sending qualified lead alerts and activity notifications to a Clay webhook
- **n8n** for sending qualified lead alerts and activity notifications to an n8n webhook
- **HeyReach** for sending qualified leads to a campaign or lead list
- **Meta Ads** for value-based audience CSV exports

## Manual vs automatic delivery

Slack, HubSpot, Webhook, Zapier, Clay, n8n, and HeyReach delivery can work in two ways:

- **Manual delivery** from the leads table when you want to review each lead first
- **Automatic delivery** when you want `traxy` to route qualified leads as soon as they meet your threshold
- **Repeat engagement delivery** for Slack, Webhook, Zapier, Clay, and n8n when you want another alert after an existing qualified lead engages again

Automatic delivery is non-retroactive. It sends leads that qualify after auto-send is turned on.

Repeat engagement delivery only works when the Slack, Webhook, Zapier, Clay, or n8n trigger and auto-send are both enabled. If you turn auto-send off, repeat engagement delivery turns off too.

Use test sends before you go live. Test sends and manual sends are single-attempt checks. Automatic delivery retries after temporary failures and may pause if repeated failures are not fixed.

If you send manually from **Leads**, you may see states such as queued, delivered, or failed. Fix the underlying integration issue first, then retry from the lead.

Review automatic settings carefully before you enable them for a shared workspace.

HubSpot can create or update CRM contacts and add engagement notes. Use [HubSpot](/using-traxy/integrations/hubspot) when you want qualified leads in your CRM.

HeyReach requires a configured campaign or lead list before traxy can send leads. Use [HeyReach](/using-traxy/integrations/heyreach) when you want qualified leads to enter an outbound workflow.

Meta Ads uses an audience export workflow instead of automatic lead delivery. Use [Meta Ads](/using-traxy/integrations/meta-ads) when you want to upload a value-based audience CSV to Meta.

API & MCP does not send leads automatically. Use [API & MCP](/using-traxy/integrations/api-mcp) when you need API keys or MCP access for another tool.

Ordinal uses a dedicated integration key. Use [Ordinal](/using-traxy/integrations/ordinal) to generate the key in traxy, then paste it into the traxy integration in Ordinal.
