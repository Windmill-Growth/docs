## Choose manual or automatic delivery

Slack, HubSpot, Webhook, Zapier, Clay, n8n, and HeyReach support manual delivery from **Leads**.

They can also route new qualified leads automatically when the lead meets the configured threshold. Automatic delivery starts with leads that qualify after you enable it. It does not backfill older leads.

Slack, Webhook, Zapier, Clay, and n8n can send repeat-engagement events. Repeat delivery requires the integration trigger and automatic delivery to remain enabled.

Use a test send before you rely on a destination. A webhook-style test is one immediate request. Lead deliveries can retry temporary failures. Automatic delivery can pause after repeated failures.

## Choose the right data connection

- Use **API** for application code that reads REST endpoints.
- Use **Claude** for Claude web, desktop, or Claude Code.
- Use **Codex** for ChatGPT and Codex surfaces.
- Use **Ordinal** for the dedicated aggregate audience workflow.

API keys are not required for Claude or Codex. Those connections use OAuth.
