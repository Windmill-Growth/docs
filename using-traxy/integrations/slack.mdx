title: "Slack"

Use the Slack integration when you want qualified lead alerts and workspace activity notifications inside a Slack channel.

## Before you connect Slack

Owners and admins can connect Slack and change delivery settings.

Decide which channel should receive traxy notifications before you start. If you want to use a private channel, invite `traxy.ai` into that channel first with `/invite @traxy.ai`.

## Connect Slack

1. Open **Integrations**.
2. Open **Slack**.
3. Connect your Slack workspace.
4. Select the channel that should receive notifications.
5. Enable the **Qualified Lead Detected** trigger once the channel is set.
6. Decide whether you want auto-send on or off.
7. If you turn on auto-send, set the ICP match threshold that should trigger delivery.
8. Decide whether to enable **Send repeat engagement from qualified leads**.
9. Send a test event before you rely on it.

If you connect Slack but do not select a channel, Slack stays disabled.

## Choose manual or automatic delivery

Slack can work in two ways:

- **Manual delivery** from the leads table when you want to review each lead first
- **Automatic delivery** when you want traxy to send qualified lead alerts as soon as leads meet your threshold

Automatic delivery is non-retroactive. It sends leads that qualify after auto-send is turned on.

Repeat engagement delivery only works when the integration trigger and auto-send are both enabled. If you turn auto-send off, repeat engagement delivery turns off too.

## Test and troubleshoot

Use a test send before you go live.

Test sends and manual sends are single-attempt checks. Automatic delivery retries after temporary failures and may pause if repeated failures are not fixed.

If you send manually from **Leads**, you may see states such as queued, delivered, or failed. Fix the underlying Slack issue first, then retry from the lead.

Review automatic settings carefully before you enable them for a shared workspace.
