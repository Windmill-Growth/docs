---
title: "Agent"
description: "Run automated lead discovery, set a daily credit budget, and review Agent history."
---

Use Agent when you want traxy to find people that match your approved ICP without choosing each LinkedIn post or profile yourself.

## Check Agent status

The status switch shows whether Agent is active or paused. Use it to pause or resume scheduled work.

Agent scans every hour while it is active and eligible to run. The **Today** card shows:

- leads found today
- the next scheduled run
- the daily credit budget
- the current rate per profile

Use **Run now** to request a run immediately. A run still follows your current access, allowance, and credit rules.

## Set the daily budget

Use the daily budget control to decide how many credits Agent may use each day.

The change saves when you commit the control. There is no separate save button.

A larger budget lets Agent examine more profiles. It does not guarantee a fixed number of qualified leads because qualification depends on your ICP and the profiles examined.

<Info>
  The Standard Pro Trial includes the Agent allowance shown in the app. After that allowance, Agent uses credits for each unique profile it scans during the billing period.
</Info>

## Review targeting

**What it looks for** summarizes the active ICP Agent uses.

Open **ICP Configuration** when you want to change job titles, departments, seniority, locations, company criteria, keywords, or the company summary. Agent does not keep a separate targeting configuration.

## Review run history

Use the calendar and run list to inspect recent work. A run can show:

- profiles scanned
- leads saved
- credits used
- run status

Open a run when candidate details are available. If a run cannot start, review the status message, daily budget, current credits, and trial or plan access.

## Agent and Watchlist

Agent and Watchlist use different discovery paths:

- Agent scans matching profiles based on your ICP and budget.
- Watchlist monitors selected LinkedIn profiles and qualifies people who engage with their posts.

Use both when you want broad discovery and account-specific signals.
