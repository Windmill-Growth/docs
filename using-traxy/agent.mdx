---
title: "Agent"
description: "Use the Agent to scan matching profiles, control daily credit spend, and review saved qualified leads in traxy."
---

Use Agent when you want `traxy` to find qualified leads from the database without choosing each post or profile manually.

The Agent starts from your approved ICP. It scans matching profiles, saves leads that fit, and tracks profile scans, saved leads, qualified leads, and credits for each run.

## Before you use Agent

Make sure your workspace has:

- an approved ICP
- available credits or an active trial allowance
- enough Watchlist and product context to guide lead quality

If the Agent is paused or blocked, open the status card first. It shows the plan, trial status when applicable, next run, and current state.

## Set the daily profile-scan plan

Open **Agent** and use **Daily profile-scan plan** to control how much work the Agent can do each day.

The daily credit budget decides how many profiles the Agent can scan. A higher budget can find more leads, but it can also use more credits.

Use the estimate in the card to see:

- expected profiles scanned per day
- profiles scanned per run
- credits the Agent can spend per day
- whether the daily budget could exceed your monthly plan if it runs every day

Click **Save plan** after you change the budget. Unsaved changes apply only after you save.

## Tune targeting

Use **Targeting your ICP** to review the approved ICP summary and add buyer-language keywords.

Add focused keywords only when you want the Agent to prioritize specific topics buyers might post, comment, or search for on LinkedIn.

For broader targeting changes, open **ICP Configuration** instead of adding many keywords.

## Run or pause the Agent

Use **Run now** when you want to start a run immediately.

Use the **Agent status** switch when you want to pause or resume scheduled runs. If a run is already in progress, wait for it to finish before changing the status.

The **Today** card shows leads found today, credits spent today, and plan usage. Unused daily Agent budget does not roll over.

## Review run history

Use **Agent run history** to inspect each run.

Each row can show:

- profiles scanned
- leads saved
- qualified leads
- credits spent
- run status

Open a run to review candidate-level details and jump into the lead record or LinkedIn profile when available.

## How Agent relates to Watchlist

Agent and Watchlist are separate discovery sources.

- Agent scans matching profiles from the database based on your ICP and budget.
- Watchlist monitors selected LinkedIn profiles and their post engagement.

Use both when you want broader lead discovery and specific signal monitoring.
