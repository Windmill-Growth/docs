---
title: "Event-related outreach"
description: "Use relevant public event context without assuming attendance or interest."
---

If a public post or interaction relates to an event, inspect the evidence and qualified lead before referencing it.

Add a relevant LinkedIn post through **Tracking** and review its audience. Do not treat a post interaction as proof of event registration, attendance, or consent to unrelated follow-up.

Save the audience, describe the event context to the Agent, and test the campaign. Check that each message uses only supported facts and that the timing still makes sense before launch.

Review replies in [Inbox](/outreach/inbox) and record actual outcomes in [Meetings](/reporting/meetings).
