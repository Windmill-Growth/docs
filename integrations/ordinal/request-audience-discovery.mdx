---
title: "Request audience discovery"
description: "Queue audience discovery for a LinkedIn post or return existing aggregate audience data."
openapi: "api-reference/customer-api-mcp-v1.openapi.yaml POST /audience-analytics/linkedin-posts/find-audience"
---

Use this endpoint when Ordinal needs traxy to discover the aggregate audience for a LinkedIn post.

Set `requalify: true` to evaluate the already-synced audience of a post against your current ICP when aggregate analytics already exist. This can use additional pipeline capacity for newly qualified leads. People already counted are not charged again. An in-progress request is returned instead of starting another.
