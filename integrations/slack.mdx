---

Connect Slack when you want lead alerts and workspace updates in your team's channels.

## Connect and test

1. Open **Integrations** > **Slack** and complete the Slack authorization.
2. In **Settings**, review the connected workspace and default channel.
3. Invite the traxy app to a private channel if it does not appear in the picker.
4. Review the available triggers, lead-reply notifications, daily summary, and message customization.
5. Save the configuration and use **Test trigger**.

The default channel receives the notifications and tests configured for it. Lead routes can use their own channels.

## Route an audience

Open **Routes** and add the lead view, destination channel, and delivery mode. You can create a channel from the channel picker when that action is available.

Follow [Route leads to other tools](/integrations/routes) for automatic delivery and sending existing leads manually.

## Review notifications

Use **Settings** to configure repeat-engagement events and daily summaries. Repeat engagement concerns new activity from a qualified lead; it is not another newly delivered lead.

If notifications stop, check the connection, trigger, route state, and channel access. Fix the issue before resuming a paused route. A successful test confirms the test request, not all future deliveries.
