---
title: "Agent runs"
description: "Review automated discovery, start a run, and inspect its results."
---

Open **Settings** > **Agent runs** to review discovery activity and pipeline capacity. The control panel also links to this area.

## Review discovery

Check whether discovery is active or paused and read any reason shown. Review the pipeline overview before requesting more leads.

A capacity stop and low supply need different responses. Capacity means the workspace has received its available leads. Low supply means discovery needs better or broader targeting and sources.

## Start and inspect a run

Use **Run now** when available, or ask the [Agent](/agent/overview) to find more leads and review its approval card.

Open a run to inspect its status, profiles scanned, results, and available candidate details. A scanned profile is not necessarily a qualified lead. Use **View leads** to review delivered results.

## If a run cannot start

Read the reason before retrying. Check workspace access, capacity, whether another run is active, and your targeting. Repeating a request does not bypass these conditions.

If discovery finds too few matches, refine [Lead criteria](/discovery/lead-criteria), review [Signals](/discovery/signals), or add relevant [tracked profiles](/discovery/tracking).
